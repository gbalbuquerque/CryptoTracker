# Crypto Tracker em React Native

O aplicativo consiste em uma busca refinada e atualizada do preço das cripto moedas que só é acessado por um esquema de login e senha salvos em um banco de dados. O programa pega o que foi digitado em uma caixa de texto e em seguida a moeda que foi pesquisada aparecerá juntamente com uma porcentagem de crescimento ou decrescimento.
## Funcionalidades

- Cadastro de Usuário
- Login de Usuário
- Visualização de Preços de Criptomoedas
- Seção de FAQ

## Tecnologias Utilizadas

- React Native
- Firebase Authentication
- CoinGecko API

## Instalação

1. Clone o repositório:
    ```sh
    git clone https://github.com/gbalbuquerque/crypto-tracker.git
    ```
2. Navegue até o diretório do projeto:
    ```sh
    cd projeto-compmovel
    ```
3. Instale as dependências:
    ```sh
    npm install
    ```
4. Configure o Firebase Authentication no arquivo `config/config.js` com suas credenciais do Firebase.

## Como Executar

1. Inicie o aplicativo:
    ```sh
    npm start
    ```
2. Abra o projeto no seu emulador Android/iOS ou use o aplicativo Expo Go no seu dispositivo físico.

## Uso

### Cadastro

1. Abra o aplicativo.
2. Navegue até a tela de cadastro.
3. Insira seu e-mail e senha.
4. Clique no botão "Cadastrar".

![image](https://github.com/gbalbuquerque/AppReact/assets/115583227/1f789bc9-05ff-4b9f-9c9d-a63e9b1686fa)
   

### Login

1. Abra o aplicativo.
2. Navegue até a tela de login.
3. Insira seu e-mail e senha.
4. Clique no botão "Logar".

![image](https://github.com/gbalbuquerque/AppReact/assets/115583227/09a53cc8-d175-4053-9c08-9bcaa8f48aa5)
![image](https://github.com/gbalbuquerque/AppReact/assets/115583227/60dfdbde-f905-4d64-a97b-bce47e510764)


### Visualizar Preços de Criptomoedas

1. Após o login, você será redirecionado para a tela de precificação.
2. Navegue pela lista de criptomoedas para ver os preços atuais.

![image](https://github.com/gbalbuquerque/AppReact/assets/115583227/34da1762-e7ba-424b-8e4a-32550fe76f38)


### FAQ

1. Na tela de precificação, clique no botão para acessar a seção de FAQ.
2. Leia as respostas para perguntas comuns.
